# Настройка iPhone

Быстрая команда раз в сутки забирает `schedule.json` у бота (Cloudflare Worker) и включает нужный будильник. Инструкция проверена на iOS 17 и 18.

Адрес файла: `https://donstu-bot.dstujarvis.workers.dev/schedule.json`. Запасной — `https://ekwsod.github.io/DONSTU_ICAL_URL/schedule.json` (GitHub Pages, тот же формат, но ночной запуск там часто опаздывает к 04:00).

## 1. Будильники

В приложении «Часы», вкладка «Будильники», создайте три будильника с такими названиями:

| Время | Название | Повтор |
|---|---|---|
| 07:00 | `Пары 07:00` | каждый день |
| 08:45 | `Пары 08:45` | каждый день |
| 10:00 | `Пары 10:00` | каждый день |

Включать их не нужно — это сделает команда. Если в `config.json` заданы другие слоты, будильники должны им соответствовать.

## 2. Быстрая команда

В приложении «Команды» создайте команду «Синхронизация будильника пар» из следующих действий.

1. **Текст**: `https://donstu-bot.dstujarvis.workers.dev/schedule.json?t=`, сразу после `=` вставьте переменную «Текущая дата» с настраиваемым форматом `yyyyMMddHHmmss`. Параметр `t` обходит кэш.
2. **Получить содержимое URL**: текст из шага 1, метод GET.
3. **Получить значение из словаря**: ключ `for_date`, словарь — содержимое URL.
4. **Форматировать дату**: «Текущая дата», настраиваемый формат `yyyy-MM-dd`.
5. **Если** значение `for_date` не совпадает с отформатированной датой:
   - **Показать уведомление**: «Расписание не обновилось, будильники не изменены.»
   - **Остановить эту быструю команду**.

   Конец условия.
6. **Получить значение из словаря**: ключ `alarm_slot`, словарь — содержимое URL.
7. **Если** `alarm_slot` совпадает с `07:00` / иначе если `08:45` / иначе если `10:00` / иначе — в каждой ветке три действия «Переключить будильник»:

   | `alarm_slot` | Пары 07:00 | Пары 08:45 | Пары 10:00 |
   |---|---|---|---|
   | `07:00` | включить | выключить | выключить |
   | `08:45` | выключить | включить | выключить |
   | `10:00` | выключить | выключить | включить |
   | иначе (пар нет, `null`) | выключить | выключить | выключить |

   Конец условия.
8. **Получить значение из словаря**: ключ `notification`.
9. **Показать уведомление**: заголовок «Расписание ДГТУ», текст — значение `notification`.

## 3. Автоматизация

1. «Команды» → «Автоматизация» → «Новая автоматизация».
2. «Время суток»: 04:00, ежедневно.
3. Выберите «Запускать немедленно» и отключите «Уведомлять при запуске».
4. Действие — команда «Синхронизация будильника пар».

04:00 выбрано с запасом: бот пересчитывает будильник в 02:00 и ещё раз в 03:30 по Москве, чтобы подхватить ночные изменения расписания.

## Поля schedule.json

| Поле | Значение |
|---|---|
| `for_date` | дата, на которую рассчитан будильник (`YYYY-MM-DD`, Москва) |
| `alarm_slot` | слот из `config.json` или `null`, если пар нет |
| `notification` | готовый текст уведомления |
| `has_lessons`, `lessons_count` | есть ли пары и сколько их |
| `first_lesson`, `first_title`, `first_room` | время, предмет и аудитория первой пары |
| `warning` | предупреждение, если даже самый ранний слот позже расчётного времени |
| `all_slots` | все слоты из конфигурации |
| `generated_at` | время генерации |
| `tomorrow` | те же поля на завтра |
